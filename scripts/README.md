# scripts/

Script triển khai và tiện ích (deploy frontend, nạp dữ liệu persona, đặt lại tài khoản demo...). Proposal §14, §13 (nút đặt lại cho giám khảo).

- `gen_contracts.mjs`: sinh Zod (`frontend/src/contracts/blocks.ts`) từ `contracts/blocks/*.schema.json`; `--check` báo lệch. Xem [contracts/README.md](../contracts/README.md).
- `migrate.py`: gọi Lambda `yofina-migrator` chạy `db/migrations/*.sql` chưa chạy (`--dry-run` chỉ liệt kê); `--seed` nạp `db/seed/*.sql` (bảng tra `tx_type_map`, `fee_schedules`, `jar_templates`; version `seed_<tên>_<sha256 8 ký tự>`, viết lại được). Xem [../db/README.md](../db/README.md).
- `db_local_check.py`: chạy thử mọi migration và seed trên PostgreSQL cục bộ (pgserver, Python 3.12 tự ghim) rồi kiểm RLS, ràng buộc, quyền và hàm đọc; không gọi AWS. `uv run scripts/db_local_check.py`.
- `seed_demo.py` (luồng B): gán nhóm Cognito `persona-*` cho 6 tài khoản demo theo `data/personas/accounts.json` (và nhóm `ops` chỉ cho tài khoản trong `ops_accounts`, hiện là `minh`; gỡ `ops` khỏi mọi tài khoản demo khác, từ chối `giamkhao*`) rồi đăng nhập SRP từng tài khoản và gọi `POST /demo/reset` (xóa dữ liệu của chính tài khoản đó, sinh lại persona, đặt đồng hồ mô phỏng về ngày neo). Chạy lại bao nhiêu lần cũng được: `uv run scripts/seed_demo.py [tài khoản...]`.
- `agent_deploy.py` (bước ghép): build zip agent ARM64 -> upload `builds/agent-<hash>.zip` lên bucket artifact -> ghi SSM `/yofina/agent/zip-key` -> `cdk deploy YofinaAgent` -> chờ Runtime READY. `uv run scripts/agent_deploy.py [--skip-build] [-c khóa=giá trị]`; mỗi lần cập nhật Runtime V2 mất khoảng 5 phút. Chi tiết: [../agent/README.md](../agent/README.md).
- `measure_latency.py` (luồng B): đo p50/p95 của `GET /jars`, `POST /confirmations`, `POST /actions` và luồng chuyển hũ qua REST thật.
- `ml_backtest.py` (phase 2, luồng ML): backtest rolling-origin của `yofina_ml` trên hai họ bộ sinh tổng hợp (`--all`; `--evaluate --quick` để kiểm khói; `--write-calibration` ghi lại `ml/yofina_ml/calibration/default.py`; `uv run --with statsforecast==2.1.1 ... --statsforecast` để so với StatsForecast). Không gọi AWS. Xem [../ml/README.md](../ml/README.md) và [../docs/research/backtest-phase-2.md](../docs/research/backtest-phase-2.md).
- `build_lambda.py` (thêm `--slim`, phase 2 luồng C): gỡ thư mục `tests` (TRỪ của numpy) và tệp `.pyi` khỏi thư viện bên thứ ba để giảm zip; dùng cho `pipelines/forecast` (`--name forecast --extra ml/yofina_ml:yofina_ml --extra gateway/tools/ledger/yofina_ledger:yofina_ledger`: 46 MB nén, 156 MB giải nén).
- `build_lambda.py --keep-boto` (phase 5): mặc định script gỡ boto3/botocore khỏi zip để dùng bản có sẵn của runtime Lambda; bản đó tùy phiên bản runtime và Region (AWS không công bố trước, [tài liệu Lambda Python](https://docs.aws.amazon.com/lambda/latest/dg/lambda-python.html#python-sdk-included)) và AWS khuyên đóng SDK vào gói khi mã cần API mới. Lambda ledger cần `ListMemoryRecords(namespacePath=...)` của AgentCore Memory (có từ botocore 1.42.90) cho REST `/memory*` và "Xóa dữ liệu của tôi", nên ghim `boto3==1.44.9`, `botocore==1.44.9` trong `gateway/tools/ledger/requirements.txt` và build bằng `--keep-boto`. Lệnh đầy đủ: `LEDGER_BUILD_COMMAND` trong `infra-cdk/lib/tools-stack.ts`:

  ```bash
  uv run scripts/build_lambda.py gateway/tools/ledger --arch arm64 --keep-boto --extra data/personas:personas --extra gateway/tools/planner/yofina_planner:yofina_planner --extra gateway/tools/planner/rules:rules --extra gateway/tools/knowledge/yofina_knowledge:yofina_knowledge --extra gateway/tools/audit/yofina_audit:yofina_audit
  ```

  Đo ngày 24/11: 22,3 MB nén, 36,3 MB giải nén.
- `_demo_auth.py`: hàm dùng chung (đăng nhập SRP tài khoản demo, gọi REST bằng `urllib`); `build_lambda.py` có thêm `--extra NGUỒN[:ĐÍCH]` để đóng kèm thư mục (dữ liệu persona) vào Lambda.
- `measure_phase3.py` (phase 3, tiêu chí 9): từ máy này qua Internet, đo what-if và kiểm tra trước khi quẹt qua chat (Runtime thật; thời điểm khối đầu, chữ đầu, tổng, `model_calls`, `degraded`), `POST /affordability` (mục tiêu p95 dưới 2 giây), `ApplyGuardrail` gọi thẳng (ngưỡng 400 ms) và p50/p95 từng bước từ `step_timings` của `GET /traces/{id}`. Giãn nhịp giữa các lượt gọi model; `--same-session` để tách khởi động lạnh microVM. Kết quả thô ở `evals/results/phase3-measure-<ngày>.json`.
- `measure_wallet.py` (luồng A phase 2): đo p50/p95 của `GET /overview` và luồng ghi `record_transaction` (xác nhận rồi thực hiện), cả phía máy gọi lẫn phía Lambda (đọc `ms` của log `rest_request` trong CloudWatch); mục tiêu p95 `GET /overview` phía Lambda dưới 300 ms. Đặt lại tài khoản sau khi đo.
- `measure_scene4_pelt.py` (issue #22, cảnh 4 chạy thật): đo hệ số tăng chi tối thiểu của hũ Ăn uống trong hai tuần gần nhất để PELT (`yofina_ml.change` với `change_defaults.json` hiện tại) xác nhận điểm gãy trên lịch sử 120 ngày của `minh`; kèm bảng lệch ngày mô phỏng và độ nhạy theo seed persona. Chạy trên máy, không gọi AWS, không gọi model, không ghi gì: `uv run python scripts/measure_scene4_pelt.py [--json]`. Dùng lại `plan_shift` của `inject_behavior_shift.py`; `data/personas/samples/make_scene4_csv.py` lấy hệ số từ đây để sinh `minh_sao_ke_2_tuan.csv`. Kết quả (hệ số tối thiểu 2,1): [../docs/research/2026-11-26-canh4-pelt.md](../docs/research/2026-11-26-canh4-pelt.md).
