# tests/

Test tự động (`tests/unit/`, `tests/integration/`). Ưu tiên test: engine tất định (affordability_check, Monte Carlo, suitability, phân bổ LP), phân loại giao dịch (NFR: đúng ≥ 90% trên bộ kiểm thử persona), idempotency của sự kiện. Đánh giá agent nằm ở [../evals/](../evals/README.md).

`tests/unit/` hiện chứa test hợp đồng ([contracts/](../contracts/README.md): khối UI, tool, OpenAPI, migration 0001; `ts/` là phía Zod, `test_contracts_zod.py` chạy nó trong pytest). Chạy: `uv run pytest` (cả test của `libs/yofina_core/tests`).

Luồng B (ledger): unit test của `libs/yofina_core/tests/` (`test_confirm_tokens.py`: 13 ca của spike và tấn công bổ sung; `test_db.py`: Data API với client giả) và `tests/unit/test_ledger_service.py`, `test_ledger_rest.py`, `test_personas.py`, `test_migration_0002.py` (đồ giả chỉ ở `tests/unit/ledger_fakes.py`, không import từ mã sản phẩm).

`tests/integration/` gọi môi trường đã deploy: `uv run pytest tests/integration -m integration` (cần credential AWS của dự án; token thật của `minh` và `lan`). `test_ledger_rest.py` (REST: luồng chuyển hũ, replay, đổi tham số, token người khác, hết hạn, đua hai request cùng `jti`, cô lập người dùng, đặt lại), `test_ledger_gateway_event.py` (boto3 invoke theo dạng sự kiện Gateway cho 3 tool), `test_ledger_rls.py` (RLS thật bằng secret `yofina_app`). Các module này đặt lại `minh` và `lan` về dữ liệu ban đầu trước và sau khi chạy.

Bước ghép Gateway và Runtime (cần stack `YofinaAgent` đã deploy; helper `agentcore_helpers.py` gồm client MCP thật và client SSE AG-UI): `test_gateway_config.py` (Gateway có interceptor, engine `ENFORCE`, mỗi tool một policy `ACTIVE`, schema khớp hợp đồng, cấu hình Runtime), `test_gateway_identity.py` (client MCP với access token thật: `tools/list`, `lan` gửi `user_id` của `minh`, bỏ `user_id`, ID token bị từ chối, `NEEDS_CONFIRMATION` không ghi, token bịa, vượt hạn mức bị Cedar `-32002`, `save_turn` và đọc lại bằng REST), `test_agent_runtime.py` (gọi Runtime thật qua HTTP/SSE: số dư khớp `GET /jars`, chuyển hũ ra khối `confirm` rồi xác nhận bằng REST, ngoài phạm vi ra `notice`, `lan` không đọc được hội thoại của `minh`, trần model bằng 0 vẫn ra khối số liệu và `notice`; mỗi lượt gọi 2 lượt model Nova, giãn 4 giây). Tổng khoảng 15 lượt gọi model mỗi lần chạy file runtime.
