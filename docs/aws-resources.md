# Tài nguyên AWS của dự án

Danh sách mọi tài nguyên dự án tạo trên AWS, Region `ap-southeast-1`. Quy ước: tên có tiền tố `yofina-`, tag `project=yofina`. **Không ghi account ID, ARN đầy đủ, secret hay email vào file này** (repo public). Cập nhật mỗi khi tạo, đổi hoặc xóa tài nguyên; đối chiếu với tài khoản khi đóng mỗi phase.

Không thuộc dự án, không được đụng: cluster Aurora và Cognito user pool có tên bắt đầu bằng `jars-dev`.
